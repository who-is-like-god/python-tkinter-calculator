# Python Calculator

A simple desktop calculator built with **Python and Tkinter**, featuring a dark-themed user interface.

## Features

- Basic arithmetic operations (`+`, `-`, `*`, `/`, `%`)
- Operator precedence
- Decimal number support
- Input validation and error handling
- Clear (`AC`) and delete (`del`) functionality
- Dark-themed interface with hover effects

## Technologies

- Python 3
- Tkinter
- pytest (unit testing)

## Getting Started

Clone the repository and navigate to the project directory.

Run the calculator:

```bash
python calculator.py
```

## Running Tests

Install pytest if needed:

```bash
pip install pytest
```

Run the tests:

```bash
python -m pytest -v
```
